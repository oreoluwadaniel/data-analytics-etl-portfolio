# Inventory Data Dictionary

| Field | Business meaning |
|---|---|
| Product ID | Unique product identifier |
| SKU | Stock keeping unit |
| Barcode | Scanning identifier |
| Product Name | Product description |
| Brand | Product brand |
| Product Category | High-level product classification |
| Product Subcategory | Detailed classification |
| Unit of Measure | Inventory measurement unit |
| Product Status | Active/discontinued status |
| Warehouse | Physical inventory location |
| Warehouse Code | Warehouse identifier |
| Bin Location | Storage bin |
| Aisle | Warehouse aisle |
| Shelf | Warehouse shelf |
| Batch Number | Production/batch identifier |
| Lot Number | Lot identifier |
| Quantity On Hand | Physical stock quantity |
| Quantity Reserved | Stock committed to existing demand |
| Available Quantity | On-hand less reserved quantity |
| Reorder Level | Quantity at which replenishment should be triggered |
| Safety Stock | Buffer stock target |
| Maximum Stock Level | Upper inventory target |
| Supplier ID | Supplier identifier |
| Supplier Name | Supplier organization |
| Supplier Country | Supplier geography |
| Lead Time (Days) | Expected supplier lead time |
| Last Purchase Date | Most recent procurement date |
| Unit Cost | Procurement cost per unit |
| Selling Price | Listed selling price |
| Inventory Value | Quantity-on-hand value at unit cost |
| Currency | Currency code |
| Last Stock Movement Date | Latest inventory movement |
| Last Restock Date | Latest replenishment event |
| Expiry Date | Product expiry date |
| Stock Status | In Stock / Low Stock / Out of Stock / Overstock |
| Reorder Required | Replenishment flag |
